# Piedra-Papel-Tijera-Cardenas-Castro

## Sobre el proyecto y mi enfoque

En este repositorio subo el primer avance de mi juego de Piedra, Papel o Tijera hecho en Python. Lo pensé para jugarlo directamente desde la terminal de Visual Studio Code pero dándole un toque visual retro con estilo pixel art en texto. La idea es sencilla, que cualquiera pueda jugar una partida rápida contra la computadora sin depender de nadie más. Ya que este avance es solo el 50% del desarrollo, por ahora cubrí el menú principal con un bucle básico y las reglas de decisión con condicionales; y aunque todavía me falta implementar el sistema de rachas, los modos de juego y el historial, esas son cosas que tendré en cuenta para la entrega final.

## Base técnica del desarrollo

Tres cosas me ayudaron a armar esta primera versión. Lo primero que hice fue dibujar el diagrama de flujo con sus rombos de decisión para tener claro cada camino antes de tocar el código. En segundo lugar, combiné un bucle while con estructuras condicionales, operadores relacionales y operadores lógicos en Python. También importé la librería random para que la computadora pueda elegir su jugada al azar y hacer el juego funcional.
